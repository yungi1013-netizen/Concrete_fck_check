출력: 엑셀 출력은 기존 '반발경도시험' 양식(측정점 3개 = 1쪽, 28행 단위 페이지 나누기, 인쇄영역 F:O)과 막대 차트, '결과표' 시트로 만듭니다. 기본은 결과 양식만 남기고 모든 값을 숫자로 넣습니다. '관리자 모드'를 켜고 출력하면 원본처럼 수식, A~E열(Input Area), 추정식·보정표가 모두 들어가 엑셀에서 다시 계산됩니다.

타격값 처리: 20점 평균의 ±20%를 벗어난 값은 제외하고 나머지로 다시 평균하여 R로 합니다. 각도 보정치 ΔR은 처음 평균값(제외 전)의 정수부로 표에서 찾습니다. R₀ = R + ΔR.

평균값으로 채우기: 입력한 평균을 중심으로 ±편차 안의 정수 20개를 만들고 합계를 평균×20에 맞춥니다. 모든 값이 ±20% 범위 안에 들어가므로 R은 입력한 평균과 같습니다 (0.05 단위).

앤빌 · 습윤 보정: 앤빌 보정값(시험 전 테스트 앤빌을 친 값, 기준 80)으로 R′ = R × 80 / 앤빌값. 측정면 상태에 따라 기건 R, 반습윤(습하고 타격 흔적이 보임) R + 3, 습윤(완전히 젖음) R + 5. R₀ = R′ + ΔR + 습윤 보정. 엑셀 출력에서는 '타격 평균값'에 앤빌 보정 후 값이, 보정계수 칸에 각도+습윤 보정이 들어가고, 앤빌값이 80이 아니면 페이지 머리줄에 표시됩니다.

재령 보정: 재령일수 = 측정일 − 준공일. 표에서 재령일수 이하 중 가장 가까운 값의 α를 적용합니다 (3000일 이상 0.63).

추정식: 같은 R₀ 로 세 값을 계산하고, 측정점마다 고른 식의 값을 결과로 씁니다 (기본 일반). 일반 = 일본재료학회식 α(13R₀ − 184)×0.098 과 일본건축학회식 α(7.3R₀ + 100)×0.098 의 평균. 고강도(30MPa 이상) = 과학기술부식 α(15.2R₀ − 112.8)×0.1. 초고강도(40MPa 이상) = KALIS 추정식 α(1.3343R₀ + 8.1977). 엑셀 출력의 '추정 압축강도' 칸에 세 값이 모두 나오고 고른 식에 ● 표시가 붙습니다.

등급: 강도비 = 추정강도 / 설계강도 ×100. 100 이상 a, 85 이상 c, 70 이상 d, 70 미만 e (a등급이라도 경미한 손상이 있으면 b). 평가는 강도비 90 초과 건전.
